# 🚀 DevClub | Programação com IA do Zero

Projeto desenvolvido durante as 4 aulas ao vivo do evento promovido pela **DevClub**, com foco em desenvolvimento web moderno utilizando inteligência artificial para otimizar o fluxo de trabalho.

## 📅 Cronograma do Evento

* **Aula 01**: Introdução ao ambiente de desenvolvimento e estrutura base do projeto.
* **Aula 02**: Estilização avançada com CSS e integração das primeiras interações lógicas.
* **Aula 03**: Integração avançada de scripts e conexão da interface com recursos inteligentes.
* **Aula 04**: Integração final com a API de IA do Puter, soma dinâmica de gastos e estilização da lista de itens.


## 🛠️ Tecnologias e Ferramentas Utilizadas

* **HTML5** - Estruturação do conteúdo da página.
* **CSS3** - Design responsivo e estilização visual.
* **JavaScript** - Lógica de programação e dinamismo.
* **Cursor / VS Code** - Editor de código focado em desenvolvimento com IA.

## 💻 Como rodar o projeto localmente

1. Clone este repositório no seu computador:
   ```bash
   git clone https://github.com/titoandyandrade/devclub-programacao-ia.git
   ```
2. Abra a pasta do projeto no seu editor de código.
3. Execute o arquivo `index.html` usando a extensão **Live Server** ou abrindo diretamente no seu navegador de preferência.
